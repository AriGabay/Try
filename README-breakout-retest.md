# אסטרטגיית Breakout Retest — פריצה + חזרה לבדיקה

מדריך מלא לאסטרטגיית **פריצה עם רה-טסט**: מהי פריצה, למה נוצר רה-טסט, איך מאשרים אותו, אילו סימנים מבדילים בין רה-טסט אמיתי לפריצת שווא, וכיצד מיישמים את זה בפועל עם ניהול סיכונים.

> **עיקרון מנחה:** הפריצה היא ה*אירוע*, הרה-טסט הוא ה*אישור*. כניסה על הפריצה עצמה מציעה מחיר טוב אבל הסתברות נמוכה; כניסה על הרה-טסט מציעה הסתברות גבוהה יותר וסטופ הדוק יותר — במחיר של פספוס חלק מהתנועות שלא חוזרות אחורה.

---

## 1. מה זו פריצה (Breakout)?

**פריצה** = תנועת מחיר שסוגרת מעבר לרמה טכנית משמעותית שהחזיקה בעבר.

| מונח | הגדרה |
|---|---|
| **התנגדות (Resistance)** | רמת מחיר שמעליה המוכרים גברו בעבר — המחיר נעצר ונדחה ממנה כלפי מטה |
| **תמיכה (Support)** | רמת מחיר שמתחתיה הקונים גברו בעבר — המחיר נעצר וקפץ ממנה כלפי מעלה |
| **פריצה כלפי מעלה (Breakout)** | סגירה מעל התנגדות |
| **שבירה כלפי מטה (Breakdown)** | סגירה מתחת לתמיכה |
| **החלפת תפקידים (Polarity Flip)** | התנגדות שנפרצה הופכת לתמיכה, ולהפך. זה הבסיס התיאורטי לכל האסטרטגיה |

### אילו רמות "נחשבות"?
לא כל קו על הגרף שווה משהו. סדר עדיפות מהחזק לחלש:

1. **רמות נזילות אופקיות** — PDH/PDL (גבוה/נמוך של אתמול), גבוה/נמוך של סשן אסיה או לונדון, שיא/שפל שבועי.
2. **רמות שנבדקו 2–3 פעמים** — כל נגיעה מוסיפה תוקף. רמה שנגעו בה 5+ פעמים כבר "שחוקה" ונוטה להישבר.
3. **גבולות של דחיסה/טווח (Range, Consolidation)** — התכנסות של 20+ נרות; ככל שהטווח צר יותר וארוך יותר, כך הפריצה ממנו חדה יותר.
4. **גבולות של תבניות** — משולש, דגל, ראש וכתפיים, ערוץ.
5. **VWAP וממוצעים נעים מרכזיים** — דינמיים, חלשים יותר כרמת רה-טסט אבל שימושיים כאישור נוסף.

> **הערות מונחים:** *ATR* (Average True Range) — מדד תנודתיות ממוצעת לנר, משמש לקביעת גודל סטופ ולסינון רעש. *VWAP* — מחיר ממוצע משוקלל ווליום מתחילת היום. *R* — יחידת הסיכון של העסקה: המרחק בין מחיר הכניסה לסטופ. רווח של "2R" = פי שניים מהסכום שסיכנתם.

## 2. למה בכלל נוצר רה-טסט?

הרה-טסט אינו מקריות — הוא תוצאה של שלושה כוחות מכניים שפועלים מיד אחרי פריצה:

1. **מימוש רווח מהיר** — סוחרים שנכנסו לפני הפריצה או עליה סוגרים חלק מהפוזיציה. הלחץ המוכר הזה מושך את המחיר בחזרה לרמה.
2. **כיסוי שורטים ואז היעדרם** — הדלק הראשוני של הפריצה הוא סטופים של שורטיסטים שנסגרים. ברגע שהדלק נגמר, אין קונה אגרסיבי והמחיר נסוג.
3. **ציידי הזדמנות ממתינים** — כסף חכם לא רודף מחיר. הוא מציב הוראות לימיט *ברמה שנפרצה*, כי שם הסיכון מוגדר בצורה הכי הדוקה. ההוראות האלה הן שיוצרות את הקפיצה מהרה-טסט.

**מה זה אומר בפועל:** ברה-טסט מתרחשת "החלפת בעלויות" — המוכרים שהגנו על ההתנגדות מוצו, והקונים שקנו את הפריצה מגנים עליה עכשיו מלמטה. אם ההגנה הזו מחזיקה — הרמה אושרה. אם לא — הפריצה הייתה שווא.

---

## 3. איך משתמשים ברה-טסט כדי לאשר פריצה?

הרצף המלא, שלב אחרי שלב:

```
רמה מוגדרת → פריצה עם עוצמה → התרחקות (Displacement) → חזרה לרמה → תגובה מוכחת → כניסה
```

| שלב | מה מחפשים | פסילה |
|---|---|---|
| **1. הרמה** | רמה ברורה שנבדקה לפחות פעמיים | קו שרירותי / רמה שחוקה |
| **2. הפריצה** | **סגירת נר** מעבר לרמה, לא רק פתיל | סגירה חזרה בפנים = פריצת שווא |
| **3. עוצמה** | גוף נר גדול (≥ 1.5× ATR או ≥ 1.5× ממוצע גוף), ווליום מעל ממוצע | נר קטן וחסר ווליום |
| **4. התרחקות** | המחיר מתרחק לפחות ~1× ATR מהרמה לפני החזרה | חזרה מיידית ללא התרחקות = "פריצה ופנייה" |
| **5. הרה-טסט** | חזרה לאזור הרמה, רצוי תוך 3–15 נרות | חזרה מאוחרת מדי (הרמה כבר לא רלוונטית) |
| **6. התגובה** | נר דחייה/בליעה מהרמה, ווליום נמוך בחזרה וגבוה בקפיצה | סגירה מתחת לרמה = הפריצה בוטלה |
| **7. הכניסה** | על סגירת נר האישור, או בלימיט באזור עם סטופ מתחתיו | כניסה "על תקווה" בלי נר אישור |

### דוגמה מספרית (לונג)
מניה נסחרת בטווח 98–100 במשך שבועיים. **100 = התנגדות** שנבדקה 4 פעמים.

1. נר יומי סוגר ב-**102.4** עם ווליום פי 2.3 מהממוצע → פריצה מאושרת (סגירה + עוצמה + ווליום).
2. המחיר ממשיך ל-**104** ביומיים (התרחקות ברורה).
3. ביום הרביעי המחיר נסוג ל-**100.3**, בווליום *נמוך* — סימן שזו נסיגה, לא היפוך.
4. נר יומי עם פתיל תחתון ארוך נוגע ב-**99.8** וסוגר ב-**101.6** → נר דחייה. ההתנגדות הפכה לתמיכה.
5. **כניסה** ב-101.6, **סטופ** ב-99.3 (מתחת לשפל הרה-טסט + מרווח), **יעד** 108 = גובה הטווח (2 נק') כפול 3 מעל הפריצה, יחס סיכון-סיכוי ≈ 2.8:1.

### דוגמה תוך-יומית (שורט)
חוזה עתידי בטיים-פריים 5 דקות. **הנמוך של אתמול = 20,150**, רמה שנבדקה פעמיים בבוקר והחזיקה.

1. נר שובר וסוגר ב-**20,132** — 18 נקודות מתחת לרמה, גוף גדול, ווליום פי 2 מהממוצע.
2. המחיר ממשיך ל-**20,110** (התרחקות של יותר מ-1×ATR) — הפריצה הוכיחה את עצמה.
3. חמישה נרות אחר כך המחיר מתקן חזרה ל-**20,148** — לתוך אזור הרה-טסט סביב 20,150, בווליום דועך.
4. נר עם פתיל עליון ארוך נדחה מ-20,152 וסוגר ב-**20,128**, מתחת לנמוך של הנר הקודם → נר אישור.
5. **כניסה** ב-20,128, **סטופ** ב-20,157 (מעל הגבוה של הרה-טסט + מרווח), **יעד** 20,041 — הקרנת רגל הפריצה. יחס ≈ 3:1.

> שימו לב שהרה-טסט כאן הוא **תנאי חובה לכניסה**, ולא המלצה. פריצה ללא חזרה ואישור אינה עסקה — היא הזדמנות שוויתרנו עליה במודע.

## 4. סימנים לרה-טסט תקין (Checklist)

### ✅ סימנים חיוביים

| קטגוריה | סימן | למה זה חשוב |
|---|---|---|
| **ווליום** | ווליום **יורד** בחזרה לרמה, **עולה** בקפיצה ממנה | חזרה עצלה = אין מוכרים אמיתיים; קפיצה עם ווליום = קונים אמיתיים |
| **נרות** | פתיל ארוך *נגד* כיוון הרה-טסט (Pin Bar), נר בליעה (Engulfing), Inside Bar ואז פריצה | הוכחה ויזואלית שהצד השני נדחה |
| **דיוק** | הרמה נבדקת ולא נחצית — או נחצית בפתיל בלבד | פתיל = מבחן; סגירה = כישלון |
| **מבנה** | הרה-טסט יוצר **Higher Low** (בלונג) או **Lower High** (בשורט) | המבנה החדש נשמר — המגמה שלמה |
| **זמן** | הרה-טסט מגיע תוך 3–15 נרות מהפריצה | מהיר מדי = לא הייתה התרחקות; איטי מדי = הרמה התיישנה |
| **עומק** | הרה-טסט לא חודר מעבר ל-~50% מגוף נר הפריצה | חדירה עמוקה = הפריצה נספגה |
| **הקשר** | הרה-טסט מתיישר עם רמה נוספת (VWAP, ממוצע נע, קצה FVG) | **Confluence** — מספר סיבות באותו מחיר מגדילות הסתברות |
| **מגמה רחבה** | הפריצה בכיוון המגמה בטיים-פריים גבוה יותר | פריצות נגד המגמה נכשלות בשיעור גבוה בהרבה |

### ❌ סימני אזהרה

- ווליום **גדל** בזמן החזרה לרמה — מוכרים אמיתיים, לא מימוש רווח.
- המחיר **סוגר** מעבר לרמה בחזרה (בלונג: סגירה מתחת לתמיכה החדשה) — הפריצה בוטלה.
- הרה-טסט "דביק": 5+ נרות דשדוש *על* הרמה בלי דחייה ברורה — הרמה מתפוררת.
- נר הפריצה היה פתיל בלבד ללא סגירה מעבר לרמה.
- הפריצה קרתה בשעה דלת נזילות (סוף סשן, לפני חג, שעות אסיה במניות אמריקאיות).
- הפריצה קרתה **על** הודעת מאקרו — התנודתיות מלאכותית וההמשך לא אמין.

## 5. סיכונים ופריצות שווא

### 5.1 סוגי הכישלון הנפוצים

| סוג | מה קורה | הגנה |
|---|---|---|
| **False Breakout / Fakeout** | פריצה, ואז חזרה מיידית לתוך הטווח | דרישת **סגירת נר** + התרחקות מינימלית לפני שמחשיבים פריצה |
| **Stop Hunt / Liquidity Sweep** | פתיל חוצה את הרמה כדי לאסוף סטופים, ומיד חוזר | לא להיכנס על פתיל; לחכות לסגירה או לכניסה מחדש |
| **Bull/Bear Trap** | הפריצה נראית מושלמת, הרה-טסט מחזיק, ואז המחיר קורס | ניהול סיכון — הפסד מוגדר מראש הופך את זה לעסק ולא לאסון |
| **פספוס (No Retest)** | המחיר בורח בלי לחזור אף פעם | להיכנס בחצי גודל על הפריצה ולהוסיף על רה-טסט, או פשוט לוותר על העסקה |
| **רה-טסט "אינסופי"** | המחיר מדשדש על הרמה ימים | תוקף זמן לסטאפ — אחרי N נרות בלי תגובה, בטלו אותו |

### 5.2 הפער בין תיאוריה למציאות
- **לא כל פריצה מקבלת רה-טסט.** בפריצות החזקות ביותר — בדיוק אלה שהכי כדאי לתפוס — המחיר לא חוזר. זו עלות מובנית של האסטרטגיה, לא באג.
- **רה-טסט הוא אזור, לא מחיר.** הצבת לימיט על הסנט/הטיק המדויק של הרמה גורמת לפספוסים מיותרים. עבדו עם אזור ברוחב ~0.25–0.5 × ATR.
- **הטיית הדגימה בגרפים היסטוריים.** בגרף אחורה קל לראות רק את הרה-טסטים שעבדו. חובה לבדוק את האסטרטגיה על מדגם רחב ובזמן אמת.
- **החלפת התפקידים לא תמיד קורית.** בשוק חסר מגמה, רמות פשוט מפסיקות להיות רלוונטיות.

## 6. יישום מעשי — שלב אחר שלב

### שלב 0 — הכנה (לפני השוק)
1. סמנו 3–5 רמות משמעותיות בלבד לכל נכס. יותר מזה = רעש.
2. קבעו את **הטיית המגמה** בטיים-פריים גבוה פי 4–6 מטיים-פריים הכניסה (למשל: כניסה ב-5 דק' → הטיה ב-1 שעה).
3. ודאו שאין הודעת מאקרו בשעה הקרובה.

### שלב 1 — זיהוי הפריצה
- המתינו ל**סגירת נר** מעבר לרמה. פתיל אינו פריצה.
- דרשו עוצמה: גוף ≥ 1.5× ATR או ווליום ≥ 1.5× ממוצע 20.
- אם אין עוצמה — סמנו את הרמה כ"נשחקה" והמתינו, אל תיכנסו.

### שלב 2 — המתנה לרה-טסט
- הגדירו **אזור רה-טסט**: מהרמה עצמה ועד ~0.3 × ATR מעברה, או קצה ה-FVG שנוצר בפריצה.
- הגדירו **חלון תוקף**: אם המחיר לא חוזר תוך N נרות (למשל 20), בטלו את הסטאפ.
- **אל תיכנסו** רק כי המחיר נגע באזור. נגיעה ≠ אישור.

### שלב 3 — האישור והכניסה
בחרו שיטת כניסה מראש ודבקו בה:

| שיטה | תיאור | יתרון / חיסרון |
|---|---|---|
| **A — כניסת אישור** | ממתינים לנר דחייה שנסגר בכיוון העסקה, ונכנסים על סגירתו | הכי בטוח / מחיר גרוע יותר, סטופ רחב יותר |
| **B — לימיט באזור** | הוראת לימיט בקצה האזור, סטופ מיד מעבר | מחיר מצוין / נתפס גם בפריצות שווא |
| **C — היברידי** | חצי גודל בלימיט, חצי על נר האישור | פשרה מעשית — מומלץ למתחילים |

### שלב 4 — סטופ ויעד
- **סטופ:** מעבר לקצה הרה-טסט (שפל הרה-טסט בלונג) **בתוספת מרווח** של 0.2–0.5 × ATR. הצבת סטופ בדיוק על הרמה = הזמנה להישאב בסוויפ.
- **יעד 1:** גובה הטווח/התבנית שנפרצה, מוקרן מנקודת הפריצה (Measured Move).
- **יעד 2:** רמת הנזילות הבאה (PDH/PDL, שיא/שפל סשן).
- **סף מינימלי:** אל תיכנסו לעסקה מתחת ליחס **1:2** סיכון-סיכוי.

### שלב 5 — ניהול סיכונים
- **סיכון לעסקה:** 0.5%–1% מההון. לא יותר, גם כשהסטאפ "מושלם".
- **גודל פוזיציה:** `גודל = (הון × אחוז סיכון) ÷ (מרחק הסטופ בנקודות × שווי נקודה)`. הסטופ קובע את הגודל, לא להפך.
- **העברה לאיזון (Break-Even):** אחרי שהמחיר עבר ~1R לטובתכם.
- **מימוש חלקי:** 50% ביעד 1, השאר עם סטופ נגרר מתחת ל-Higher Lows.
- **מגבלת הפסדים יומית:** 2–3 הפסדים ברצף = סיום היום. פריצות שווא באות בסדרות.

### שלב 6 — תיעוד ובקרה
נהלו יומן עם: הרמה, טיים-פריים, ווליום הפריצה, עומק הרה-טסט, זמן עד הרה-טסט, שיטת הכניסה, R שהושג. אחרי 30–50 עסקאות תדעו **אילו** רה-טסטים עובדים עבורכם — ותוכלו לסנן את השאר.

## 7. תקציר מהיר

| שאלה | תשובה |
|---|---|
| מה מאשר פריצה? | **סגירת** נר מעבר לרמה, עם גוף גדול וווליום מעל ממוצע |
| מה מאשר רה-טסט? | חזרה בווליום נמוך + נר דחייה + שמירה על מבנה (HL/LH) |
| מתי לפסול? | סגירה בחזרה מעבר לרמה, ווליום גדל בחזרה, או פקיעת חלון הזמן |
| איפה הסטופ? | מעבר לקצה הרה-טסט + מרווח ATR — לא על הרמה עצמה |
| מה היחס המינימלי? | 1:2. אחרת אין עסקה |
| מה הטעות הנפוצה? | כניסה על פתיל במקום על סגירה, ורדיפה אחרי פריצה שכבר ברחה |

## 8. האינדיקטור — [`breakout-retest-signals.pine`](breakout-retest-signals.pine)

מימוש Pine Script v6 של כל מה שלמעלה, שמסמן על הגרף **כניסה** ו**יציאה** לכל עסקה.

הקובץ עומד בפני עצמו — אין לו תלות בשום קובץ אחר, ואין צורך בסימבול השוואה או בהגדרת סשנים. מריצים אותו על כל נכס ועל כל טיים-פריים.

### מה הוא מצייר
| אובייקט | משמעות |
|---|---|
| קו מקווקו אפור (Shelf) | רמה פעילה. ככל שיש יותר בדיקות — הקו עבה וכהה יותר |
| קופסה צבועה | אזור הרה-טסט (רוחב `± Retest zone half-width × ATR` סביב הרמה), פעילה כל עוד הסטאפ ממתין |
| ▲ / ▼ + תווית | **כניסה**: מחיר, סטופ, יעד שני, יחס R:R וגודל פוזיציה מחושב |
| קו אדום עבה | הסטופ. כשהוא עולה לאיזון אחרי היעד הראשון — הקטע הישן נסגר ומתחיל קטע חדש, כך שרואים בדיוק איפה הוזז |
| קו ירוק מקווקו / עבה | יעד ראשון / יעד שני |
| תווית `T1 +1R · 50%` | מימוש חלקי |
| תווית `EXIT ... ±R` + ✕ | **יציאה** — עם ה-R שנסגר בפועל |
| טבלה בפינה | עסקאות, אחוז פגיעה, Win/Loss/Flat, סה"כ R, ממוצע R, והפוזיציה הפתוחה |

### מכונת המצבים
```
Shelf → סגירה מעבר לרמה (+ סינון עוצמה) → Thrust ≥ 1×ATR
      → חזרה לאזור → נר דחייה → כניסה → ניהול → יציאה
```
פסילה אוטומטית: סגירה חזרה מעבר לרמה, אי-חזרה תוך `Latest retest` נרות, סטופ רחב מדי, או יחס R:R מתחת לסף.

### הגדרות שכדאי לכוונן ראשונות
| הגדרה | ברירת מחדל | מתי לשנות |
|---|---|---|
| `Force filter` | Body or volume | לנכסים ללא ווליום אמיתי (פורקס, קריפטו ספוט) — העבירו ל-`Body only` |
| `Thrust required before a retest` | 1.0 × ATR | הורידו ל-0.5 בטיים-פריים נמוך, העלו ל-1.5 בשוק תנודתי |
| `Retest zone half-width` | 0.30 × ATR | צר מדי = פספוסים; רחב מדי = כניסות מוקדמות |
| `Tests required before a break counts` | 1 | העלו ל-2–3 כדי לסחור רק רמות שהשוק כבר הגן עליהן |
| `Second target` | R multiple | `Projected leg` = הקרנת רגל הפריצה מנקודת הכניסה (Measured Move) |
| `Skip anything below this R:R` | 2.0 | הסף מהמסמך. הורדה מתחת ל-1.5 שוחקת את התוחלת |

### התקנה
`Pine Editor` → הדביקו את תוכן `breakout-retest-signals.pine` → **Add to chart**.
התראות: `Add alert` → בחרו `Breakout retest — long entry` / `short entry` / `exit`, או השתמשו ב-`alert()` הדינמי שכולל מחיר, סטופ ויעדים בגוף ההודעה.

> **על הטבלה הסטטיסטית:** זו ספירה על הגרף, **לא בק-טסט**. ההנחה היא מילוי במחיר המדויק של הסטופ/היעד, ללא סליפג' ועמלות, וכשנר מכיל גם את הסטופ וגם יעד — הוא נספר כסטופ (הנחה שמרנית). השתמשו בה כדי להשוות הגדרות זו לזו, לא כדוח ביצועים.

### אין Repaint
כל המעברים מתבצעים תחת `barstate.isconfirmed` בלבד, פיבוט מאושר רק אחרי שנסגרו `Pivot bars — right` נרות אחריו, וה-`request.security` לרמות היום הקודם משתמש ב-`lookahead_off` על נר סגור. כניסה שסומנה בהיסטוריה היא הכניסה שהייתה נורית בזמן אמת.
