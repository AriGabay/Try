# אינדיקטור NQ/ES — ‏SMT + IFVG + ווליום (Pine Script v6)

אינדיקטור ל-TradingView שמזהה **חוסר קורלציה (SMT) בין NQ ל-ES בפתיחות סשנים**, ומאותת לונג/שורט באמצעות **IFVG ‏(Inversion Fair Value Gap)**, עם **דירוג עוצמה לפי ווליום**. כל שעות הסשנים מוגדרות **בשעון ישראל**.

## התקנה
1. פתחו גרף ב-TradingView (מומלץ: ‏`CME_MINI:NQ1!` בטיים-פריים 1–5 דקות).
2. פתחו את ה-Pine Editor (תחתית המסך) → הדביקו את תוכן הקובץ `nq-es-smt-ifvg-volume.pine` → ‏"Add to chart".

## איך האיתות עובד
האיתות בנוי משלוש שכבות:

### 1. ‏SMT — דיברגנס בפתיחת סשן (NQ מול ES)
בכל פתיחת סשן (אסיה / לונדון / NY AM ‏/ NY PM) האינדיקטור משווה את **מחיר פתיחת הסשן** מול **סגירת הסשן הקודם** — גם בגרף הנוכחי וגם בסימבול המקביל (זיהוי אוטומטי: גרף NQ ⇒ השוואה ל-ES1!, גרף ES ⇒ השוואה ל-NQ1!).

דוגמה: אם NQ פותח את סשן אסיה **מתחת** לסגירת סשן ניו יורק, אבל ES פותח **מעל** — זה חוסר קורלציה (SMT divergence). מסומן בתווית סגולה ("SMT") ונפתח **חלון SMT פעיל** שנמשך עד סוף הסשן.

### 2. ‏IFVG — האות הכיווני
- ‏FVG שורי: ‏`low > high[2]`; ‏FVG דובי: ‏`high < low[2]` (מסונן לפי רוחב מינימלי של ‏ATR(200) ‏× 0.25).
- כשנר **סוגר** מעבר ל-FVG (ברירת מחדל: לפי Close; אפשר Wick) — ה-FVG מתהפך והופך ל-IFVG (הקופסה משנה צבע).
- **לונג** 🟢: בתוך חלון SMT פעיל, ‏FVG דובי נשבר כלפי מעלה (הפך לזון תמיכה).
- **שורט** 🔴: בתוך חלון SMT פעיל, ‏FVG שורי נשבר כלפי מטה (הפך לזון התנגדות).

### 3. ווליום — דירוג עוצמה (לא תנאי כניסה)
יחס הווליום של נר האיתות מול ‏SMA(20) של הווליום:
| יחס | תווית | משמעות |
|---|---|---|
| ‏≥ 2.5 | `LONG ++` / `SHORT ++` | ספייק ווליום חזק — האיתות האיכותי ביותר |
| ‏≥ 1.5 | `LONG +` / `SHORT +` | ווליום גבוה |
| ‏< 1.5 | `LONG` / `SHORT` (מעומעם) | ווליום רגיל — איתות חלש יותר |

## סשנים (שעון ישראל — `Asia/Jerusalem`)
| סשן | ברירת מחדל | מקור (שעון ניו יורק) |
|---|---|---|
| אסיה | 01:00–09:00 | 18:00–02:00 |
| לונדון | 09:00–15:30 | 02:00–08:30 |
| ניו יורק AM | 15:30–20:00 | 08:30–13:00 |
| ניו יורק PM | 20:00–23:00 | 13:00–16:00 |

כל הסשנים ניתנים לעריכה ולכיבוי בהגדרות. ה-timezone קבוע ל-`Asia/Jerusalem`, כך ששעון קיץ/חורף מטופל אוטומטית.

## הגדרות עיקריות
| הגדרה | ברירת מחדל | הסבר |
|---|---|---|
| Comparison symbol | ריק (אוטומטי) | סימבול ההשוואה; ריק = ‏NQ↔ES אוטומטית |
| Minimum FVG width | ‏0.25 × ATR(200) | סינון גאפים זניחים (0 = ללא סינון) |
| Inversion trigger | Close | ‏Close מומלץ — פחות איתותי שווא מ-Wick |
| Max tracked gaps per side | 5 | כמה FVG-ים נשמרים לכל כיוון |
| Gap validity | 500 בארים | תוקף מקסימלי לזון |
| Volume SMA / thresholds | ‏20 / 1.5 / 2.5 | פרמטרים סטנדרטיים לפיוצ'רס תוך-יומי |

## התראות (Alerts)
צרו Alert על האינדיקטור ובחרו אחד מהתנאים:
- **Long signal** / **Short signal** — ‏SMT + IFVG
- **Strong long / Strong short** — אותו דבר + ווליום ≥ 2.5×
- **SMT divergence at session open** — התראה על עצם הדיברגנס

## הערות חשובות
- **ללא repaint**: זיהוי FVG והיפוכים נעשים רק על נרות סגורים (`barstate.isconfirmed`), ונתוני ES נמשכים עם `lookahead_off`.
- מומלץ לוודא שעל הגרף יש ווליום (חוזים עצמם, לא CFD) — אחרת הדירוג לא יעבוד.
- האינדיקטור הוא כלי ניתוח בלבד ואינו ייעוץ השקעות.

## בדיקה מהירה אחרי ההתקנה
1. גרף `NQ1!` בטיים-פריים 5 דקות.
2. ודאו שרקעי הסשנים מתחלפים ב-01:00 / 09:00 / 15:30 / 20:00 לפי שעון ישראל.
3. בפתיחת סשן עם דיברגנס תופיע תווית SMT סגולה; אם נוצר IFVG בהמשך הסשן — תופיע תווית לונג/שורט.
4. הטבלה בפינה הימנית-עליונה מציגה: סשן נוכחי, סטטוס SMT, יחס ווליום וסימבול ההשוואה.
